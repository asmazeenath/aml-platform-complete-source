# Starter scenarios
All values are illustrative demo configuration, not regulatory thresholds:
- High velocity: inbound count and distinct senders in a rolling window.
- Fan-out: distinct outgoing beneficiaries.
- Rapid movement: outflow/inflow ratio.
- Dormant activation, profile mismatch and corridor risk are extension points requiring approved institution data.
Every scenario must be versioned, tested on positive/negative synthetic cases, approved and monitored for false positives and bias.
